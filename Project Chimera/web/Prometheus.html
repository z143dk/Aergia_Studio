Phase 2: Enable The App

CRITICAL: Create OAuth 2.0 Client ID: This app needs your permission to talk to Google Cloud.
  1. Go to the Credentials page in your Google Cloud project.
  2. Click "+ CREATE CREDENTIALS" and select "OAuth client ID".
  3. For "Application type", select "Web application".
  4. Give it a name, like "Prometheus App Client".
  5. Under "Authorized JavaScript origins", click "+ ADD URI" and enter `http://localhost:8000` (or the address you run this from).
  6. Under "Authorized redirect URIs", click "+ ADD URI" and enter `http://localhost:8000`.
  7. Click "CREATE". Copy the "Client ID" you receive.
