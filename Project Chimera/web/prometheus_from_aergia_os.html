Prometheus Setup Guide

1

Save This File

Save this entire code as a new file on your computer named `prometheus.html`.

2

Create Your "Key"

This app needs a special key (an OAuth Client ID) to securely talk to your Google Cloud project. This is a one-time setup.

  1. Go to the Google Cloud Credentials page.
  2. Click "+ CREATE CREDENTIALS" and select "OAuth client ID".
  3. For "Application type", select "Web application".
  4. Give it a name, like "Prometheus Engine Client".
  5. Under "Authorized JavaScript origins", click "+ ADD URI" and enter `http://localhost:8000`.
  6. Click "CREATE". A window will pop up. **Copy the "Client ID"** it gives you.
3

Run a Local Server

You cannot just double-click the file. Open a terminal, navigate to where you saved `prometheus.html`, and run:

python -m http.server 8000
4

Launch Prometheus

Open your browser and go to:

http://localhost:8000/prometheus.html

Paste your Client ID into the app, sign in, and start creating!
